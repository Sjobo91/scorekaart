# Scorekaart Selectie

Een formulier om sollicitatiegesprekken eerlijk te beoordelen. Eerst ieder voor zich scoren, dan samen besluiten.

Gemaakt voor de selectiecommissies van gemeente Deventer. Prototype.

## Hoe het werkt

1. Maak een vacature aan en plak de vacaturetekst.
2. Vul de criteria in, of laat Claude de voorbereiding maken.
3. Voeg kandidaten toe met een code.
4. Iedereen in de commissie beoordeelt apart. De uitslag opent pas als iedereen klaar is.
5. Bespreek de verschillen en leg het besluit vast.

## Techniek

* Losse HTML, CSS en JavaScript. Geen build.
* Gegevens en inloggen via Supabase (EU, Frankfurt). Alleen leden die de beheerder toevoegt kunnen inloggen.
* De code in deze repo is openbaar. De gegevens niet.
